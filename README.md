# my-knowledge-base

A versioned personal knowledge base — periodically updated with notes, goals, learnings, and more.

## Structure

| Directory | Description |
|-----------|-------------|
| [`books/`](./books/) | Reading list and book notes |
| [`goals/`](./goals/) | Short-term and long-term goals |
| [`health/`](./health/) | Fitness, wellness, and habit tracking notes |
| [`finance/`](./finance/) | Financial planning and tracking notes |
| [`learning/`](./learning/) | Skills, courses, and learning resources |
| [`projects/`](./projects/) | Personal project ideas and progress |
| [`journal/`](./journal/) | Reflections and periodic notes |
